Your data & privacy

Snapscape processes your selected photos in this browser and stores resized puzzle images, your unfinished puzzle, finished memories, and points here. The app does not upload your photos or send gameplay analytics. It uses browser storage to remember progress and does not set tracking cookies.

Use Options → Back up memories to download a copy, or Options → Erase browser storage to delete Snapscape’s saved data from this browser. Backups contain your puzzle photos and progress. Your original photo files are not changed.

When you visit the GitHub Pages version, GitHub logs visitors’ IP addresses for security purposes. See GitHub Pages data collection and the GitHub Privacy Statement. Following external links takes you to services with their own privacy practices.
